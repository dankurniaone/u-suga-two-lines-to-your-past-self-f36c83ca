`main.ts` (Node 22, stdlib only) writes exactly two lines to `/output/entry.txt`:

> Don't tell the customer the bug is fixed before you've run the test — say 'checking' instead.
> That one sentence cost you the deploy, the weekend, and the only customer who ever trusted you.

Line one warns the past self about one specific moment — a sentence said out loud before the test was run. Line two traces the cause and effect: that sentence cost the deploy, the weekend, and the only customer who ever trusted the agent. The program validates the gate (1–280 characters, exactly two lines, each a single sentence, line two not a restatement of line one) and verifies the round trip by reading the file back.
